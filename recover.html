🛠️ 数据恢复工具

这个工具专门用来在被登录门禁挡住时，把你浏览器里原本存着的数据取出来。它不会要求你登录，也不会上传任何东西，只是把数据读出来给你下载。

正在读取本浏览器存储…
怎么用这个工具：
1. 用当初录入产品时同一个浏览器打开本文件（本地双击 recover.html，或线上版本的 /recover.html）。
2. 如果上面显示找到了产品 → 点「下载备份」，得到一个 .json 文件。
3. 打开线上工作台 https://panda123auv.github.io/PYN-workbuddy/，用邮箱登录，进入「下载」页面，点「⬆️ 上传恢复」选这个 json。
4. 数据会自动重新加密并同步到你的云端账号，之后换设备登录就能拉回来。

如果这里显示 0 条 / 未找到：说明数据不在这个"打开方式"的存储里。请换一个打开方式再试——
· 现在是在线上网址打开的 → 改用本地文件双击打开本工具；
· 现在是在本地文件打开的 → 改用线上网址的 /recover.html 打开。
